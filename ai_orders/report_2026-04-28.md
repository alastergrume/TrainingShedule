### 1. Исправление критических багов

| Файл | Проблема | Исправление |
|------|----------|-------------|
| `src/celery_app.py` | `with next(get_db()) as db` — генератор не является контекстным менеджером | Заменено на `SessionLocal()` + `try/finally/db.close()` |
| `src/celery_app.py` | `Booking.status == 'confirmed'` — строковый литерал вместо enum | Заменено на `BookingStatus.CONFIRMED` |
| `src/business_logic/services/schedule_service.py` | `.first().first_name` — падение при отсутствии пользователя | Выделен метод `_get_user_name()` с проверкой на `None` |
| `src/business_logic/services/schedule_service.py` | Проверка вместимости по `training_id` — проверяла все недели | Исправлено на проверку по `schedule_entry_id` |
| `src/business_logic/schemas/__init__.py` | `regex=` (Pydantic v1) не работает в Pydantic v2 | Заменено на `pattern=` |
| `migrations/versions/initial_migration_20250427.py` | Двойное создание ENUM типов приводило к ошибке | Добавлен `checkfirst=True` + `create_type=False` на ссылках |
| `src/messengers/vk/bot.py` | Синхронные вызовы VK API блокировали event loop | Обёрнуты в `asyncio.to_thread()` |

### 2. Новые возможности

#### Telegram-бот — полный рерайт ([src/messengers/telegram/bot.py](../src/messengers/telegram/bot.py))

**Команды пользователя:**
- `/start` — приветствие с кнопкой «записаться», администраторам показывает `/admin`
- `/schedule` — расписание текущей недели из базы данных
- `/book` — список доступных тренировок с инлайн-клавиатурой для записи
- `/cancel` — выход из FSM-состояния

**Административная панель (`/admin`):**
- 📅 Просмотр расписания по неделям
- ⚡ Генерация расписания из шаблонов
- 📢 Публикация расписания в канал (превью → подтверждение → публикация через Celery)
- 📋 Управление шаблонами тренировок: список с пагинацией, просмотр, удаление
- ➕ Добавление шаблона через FSM (6 шагов: название → тип → день → время → длительность → участники)
- 👥 Подтверждение/отклонение заявок на запись с уведомлением пользователя
- ✏️ Кнопка открытия Mini App для ручного редактирования расписания

**FSM-состояния (AddTraining):**
```
title → training_type → day_of_week → start_time → duration → max_participants → confirm/cancel
```

#### Telegram Mini App ([src/static/miniapp/index.html](../src/static/miniapp/index.html))
- Навигация по неделям
- Карточки тренировок с раскрытием деталей
- Управление участниками (коммерческие и персональные тренировки)
- Чекбоксы оплаты для каждого участника
- Редактирование времени тренировки
- Отмена занятия
- Кнопки «Генерировать» и «Опубликовать» расписание
- Адаптируется под тему Telegram (CSS-переменные `--tg-theme-*`)

## Как запустить

```bash
# 1. Скопировать и заполнить .env
cp .env.example .env
# Заполнить: TELEGRAM_BOT_TOKEN, TELEGRAM_ADMIN_IDS, TELEGRAM_CHANNEL_ID, MINIAPP_URL

# 2. Запустить все сервисы
docker compose up --build

# Сервисы: postgres, redis, migrate (one-shot), app (FastAPI), celery, celery-beat, telegram-bot
```

**Mini App** требует HTTPS для работы в Telegram. Для локальной разработки — ngrok:
```bash
ngrok http 8000
# Указать полученный URL в MINIAPP_URL в .env
```
